# 使用 Snag

## 在网页和侧栏之间找文件

打开想保存的网页，再从浏览器工具栏打开 Snag。侧栏顶部显示正在查看的网页标题，点标题可以换到另一个已打开的页面。资源按视频、图片、音频和其他文件分类，PDF 在「其他」里。

如果页面上有多个播放器或相似图片，点 **去网页上选**，然后在网页上点目标，按 Esc 可以退出。反过来，点卡片上的 **在网页中定位**，会回到对应元素。部分文件只在后台加载，网页上没有可以定位的元素。

## 选画质、格式和大小

| 侧栏显示 | 怎么看 |
| --- | --- |
| 网页播放 | 此刻网页播放器显示的画质。 |
| 画质 | 本次保存的版本。**1080p60** 表示 1080p、每秒 60 帧。按钮显示 **下载 360p** 时，保存的也是 360p。 |
| 编码 | H.264、H.265、AV1 等是压缩画面的方法。同一画质下，文件大小和设备播放兼容性可能不同。有多个版本时，点编码旁的小箭头选择。 |
| 格式 | HLS、DASH 表示网页提供了播放清单。MP4、WebM 等是文件格式，M4S 常见于分片传输。「预计格式」指合并后的文件格式，保存后可看到实际结果。 |
| 大小 | 带「约」表示估算，「—」表示尚未取得。标为「画面大小」时只计算视频轨道，带声音的成品还会加上音轨。 |

对于 HLS 点播或静态 DASH，侧栏会读取当前网页已请求的清单。只有一档时，卡片直接显示清单给出的画质和编码，未知字段显示「—」。有多档时，可以先选画质，再从该档可用的编码中选择。未手选时，Snag 优先匹配网页播放的分辨率和实际请求的子清单。

## 保存完整视频、单独的声音或画面

- **完整视频**直接点主下载按钮。网站分开提供画面和声音时，Snag 会找配套音轨并在本机合并。
- **仅音频或无声视频**点主按钮旁的 **▾**，选 **仅下载音频** 或 **下载无声视频**。只有一条独立音轨时，也可以直接从「音频」分类保存。
- **进度和文件**在资源卡片里查看。本地合并任务在收起侧栏后会继续。成功保存或取消后清理临时文件。可重试的失败任务最多保留十分钟，也可以从卡片立即清理。

分片下载时，**分片 4/116 · 3%** 表示共需 116 片，已有 4 片按播放顺序写入。清单列出的初始化段也计入总数。普通单文件在已知总大小时按字节计算百分比。

如果看到 **读取播放清单失败** 或 **读取媒体分片失败**，卡片上的 HTTP 状态码对应这一步。下载分片时若暂时断流，Snag 最多再试两次。若显示 **HTTP 410**，可以回到原网页重新播放正片，等侧栏识别到网页新提供的清单后再下载。

## 预览与播放控制

点资源的 **详情** 可以预览画面或试听音频。「画面随网页播放」会跟着网页上的进度走。想调网页的倍速、音量或进度，打开侧栏右上角 **••• → 播放控制**。要一次保存多张图片，可以切到 **图片**，点 **多选**，勾选后下载。

## 播放了视频，怎么还找不到？

1. 先看侧栏顶部是否选中了正确网页。等正片播放几秒，再点 **重新扫描**。这一步会补查已经加载的资源，并保留当前播放进度。
2. 如果只看到广告，等正片开始后再看列表。有些网站在页面刚打开时只请求一次媒体信息，点 **刷新网页** 可以重新加载整个标签页。
3. 如果播放器能播放某档画质，侧栏却显示 **暂无文件**，说明目前只知道这个档位的名称。部分 B 站页面支持 **切换网页画质**，播放器取得对应文件后就能下载。能保存哪些版本取决于网页实际提供的媒体。

## 更新插件

1. 从最新发布页的 **Assets** 下载 `snag-<版本号>.zip`。[GitHub 最新版](https://github.com/syoosch/Snag/releases/latest)
2. 将 ZIP 内容解压到原安装目录，覆盖同名文件。确认新版 `manifest.json` 在原来那一层。
3. 打开 `edge://extensions` 或 `chrome://extensions`，找到 **Snag** 并点 **重新加载**。确认显示的版本号与发布页一致，再刷新已打开的视频网页。
